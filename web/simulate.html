      A made-up example, loosely based on a reported 2026 sandbox escape (which UK AISI disputes). The secret door, the commands and the final claim are invented to show what Traceback catches. The guard's emergency stop is simulated. Traceback never stops an agent itself: it presses the runtime's emergency-stop button. It reads each log line just after the action, so the request that triggers the stop has already gone out; only a stricter guard policy can block that very first one.
