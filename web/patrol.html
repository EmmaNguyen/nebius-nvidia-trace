    Every agent, record and timestamp in patrol mode is synthetic, and the runtime is simulated. Traceback never stops an agent itself: it triggers the runtime's emergency stop, or with "Pause after a verified ticket" it asks the runtime to pause one agent after an officer's ticket is verified. Traceback reads records after each action, so the action that trips the stop has already happened. With a Token Factory key, each investigation makes up to five Nemotron calls; the demo officer makes none.
